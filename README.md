# 🌐 מתרגם מקלדת חכם - Smart Keyboard Translator (v2.2.0)

תוסף Chrome חכם שמתקן שגיאות הקלדה בזמן אמת עבור משתמשים המקלידים בעברית ובאנגלית, עם בועת זכוכית שקופה ואישור מהיר במקש Tab.

---

## 🚀 מה חדש בגרסה 2.2.0 (שדרוג מקיף ותיקון פערים)

* **💎 בועת זכוכית שקופה (Frosted Glass Bubble):** הצעות התיקון קופצות כעת בעיצוב זכוכית שקוף מודרני (`backdrop-filter`) מעל שדה הקלט.
* **⌨️ אישור מיידי במקש Tab:** לחיצה על מקש **Tab** מאשרת ומחליפה מיד את המילה השגויה בתוצאה המתורגמת.
* **🛡️ סינון מילים חכם (מניעת False Positives):** נוסף מאגר מילים באנגלית (`COMMON_ENGLISH_WORDS`) המונע הקפצת הצעות שגויות למילים תקינות כגון `car`, `the`, `hello`, `email`, `google` ועוד.
* **🔁 מיפוי דו-כיווני מתוקן:** תיקון באגים בסימני פיסוק (פסיק/גרש/סלאש) כדי למנוע השחתת תווים בהמרה הפוכה מעברית לאנגלית.
* **🧠 היסטוריית מילים שטופלו:** התוסף אינו מקפיץ הצעות חוזרות ונשנות למילים שכבר הומרו או נדחו.
* **🖥️ סימולטור אינטרנטי מובנה:** אפליקציית Web מלאה לבדיקת התוסף ישירות בדפדפן!

## 📂 מבנה הפרויקט

```
תוסף כרום תרגום מקלדת/
├── manifest.json          # הגדרות התוסף (Manifest V3)
├── background.js          # Service Worker - מעקב ותקשורת
├── content.js             # תסריט התוכן המלא - אלגוריתם, בועת זכוכית ומקש Tab
├── popup.html             # ממשק ה-Popup המודרני
├── popup.js               # לוגיקת ה-Popup והפעלת תרגום
└── icons/                 # אייקונים בגדלים שונים
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

---

## 🛠️ התקנה ב-Google Chrome

1. פתחו את דפדפן Chrome ועברו לכתובת: `chrome://extensions/`
2. הפעילו את **Developer mode** (מצב מפתח) במתג בפינה הימנית העליונה.
3. לחצו על כפתור **Load unpacked** (טען פריט שלא נארז).
4. בחרו בתיקייה: `תוסף כרום תרגום מקלדת`.
5. התוסף מוכן ופעיל בכל אתר!

---

## 💡 כיצד להשתמש

1. **הקלדה רגילה:** הקלידו בשדה טקסט בכל אתר (כולל WhatsApp Web, פייסבוק, גוגל וכו').
2. **זיהוי שגיאה:** אם הקלדתם למשל `akuo` במקום `שלום`, תקפוץ מיד בועת זכוכית עם ההצעה **שלום**.
3. **אישור מהיר:** לחצו על מקש **Tab** ↹ או הקליקו על כפתור "החלף" בבועה.
4. **המרה ידנית:** סמנו טקסט בשדה כלשהו ולחצו על כפתור הגלובוס 🌐 הצף, או פתחו את ה-Popup ולחצו על "תרגם עכשיו את השדה הפעיל".
