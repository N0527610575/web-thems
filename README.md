# 🌐 מתרגם מקלדת חכם - Smart Keyboard Translator

תוסף Chrome חכם שמתקן שגיאות הקלדה בזמן אמת עבור משתמשים היוצרים טקסט בעברית.

## 📋 תיאור הפרויקט

זהו תוסף ל-Chrome (Chrome Extension) המיועד לשיפור חוויית ההקלדה של משתמשים הממלאים טפסים ושדות טקסט באתרים בעברית. התוסף מזהה שגיאות הקלדה וחיזוי בזמן אמת, מציע תיקונים חכמים, ומאפשר אישור מהיר בעזרת לחצני מקלדת.

## ✨ תכונות עיקריות

- **זיהוי בזמן אמת**: מזהה שגיאות הקלדה כשאתה מקליד
- **בועות התראה שקופות**: הצעות התיקון מופיעות בבועות זכוכית שקופות מעל השדה
- **אישור מהיר**: אנחסה עם מקש Tab או לחצן הפתרון הממוזער בשדה
- **חסימה חכמה**: מ��עלמת מטקסט שכבר תורגם
- **שפה טבעית**: ממשק מלא בעברית

## 📦 מבנה הפרויקט

```
תוסף כרום תרגום מקלדת/
├── manifest.json          # קונפיגורציה של התוסף
├── background.js          # Service Worker - מעקב והודעות
├── content.js             # תסריט התוכן - הלוגיקה הראשית
├── popup.html             # ממשק ה-Popup
├── popup.js               # לוגיקה של ה-Popup
└── icons/                 # אייקונים בגדלים שונים
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 🔧 מקומות רכיבים

### `manifest.json`
קונפיגורציה של התוסף:
- גרסה 3 (החדשה ביותר)
- הרשאות: `activeTab`, `storage`
- Service Worker background
- Content scripts שרצים בכל URLs

### `background.js`
Service Worker שמאזין לבקשות מ-popup ומעביר הודעות לשונית הפעילה.

### `content.js`
הלוגיקה העיקרית של התוסף - מתקן את שגיאות ההקלדה בשדות הטקסט.

### `popup.html` ו-`popup.js`
ממשק ה-Popup עם כפתור להפעלת התרגום הידנית.

## 🚀 התקנה

1. פתח את Chrome ועבור ל- `chrome://extensions/`
2. הפעל את **Developer mode** בפינה הימנית עליונה
3. לחץ על **Load unpacked**
4. בחר בתיקיית `תוסף כרום תרגום מקלדת`
5. התוסף יופעל אוטומטית!

## 📝 שימוש

1. **הקלדה פשוטה**: פשוט התחל להקליד בכל שדה טקסט באתר
2. **אישור הצעה**: הקש Tab או לחץ על הכפתור הכחול במעל הבועה
3. **פתיחת Popup**: לחץ על אייקון התוסף בסרגל הכלים
4. **הפעלה ידנית**: לחץ על כפתור "תרגם עכשיו את השדה הפעיל"

## 🔐 הרשאות

- **activeTab**: גישה ללשונית הנוכחית
- **storage**: שמירת הגדרות ובחירות המשתמש
